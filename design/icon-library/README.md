# Icon Library

This folder is the working source library for Zero Limit Agency UI icons.

## Structure

- `source/`: original icon pack files. Keep original filenames.
- `LICENSE.txt`: replace/add the original license file from the icon pack.
- This `README.md`: may be replaced by the original pack README if preferred.

Do not place the full source library in `public/`. Only production icons actually used by the app should be promoted into the appropriate runtime asset/component location.
