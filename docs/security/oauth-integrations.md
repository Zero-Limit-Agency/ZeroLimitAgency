# OAuth integration security

OAuth initiation creates 256 random bits, stores only its SHA-256 hash, and binds it to Profile, provider, an allowlisted internal return path, and a 10-minute maximum expiry. Consumption is an atomic single-use database update; invalid, expired, mismatched, and replayed state fail closed. Provider-supported PKCE uses the provider/library S256 implementation; a verifier, if persistence is necessary, is encrypted server-side.

Callbacks are provider-specific. They authenticate the current Zero Limit session, consume state before exchanging the code server-side, validate returned identity/scopes, and use the trusted deployment URL resolver: validated Vercel Preview URL, canonical production URL, or localhost in development. `Host`, arbitrary callback query values, protocol-relative URLs, and external return URLs are never trusted. Unexpected failures carry a correlation ID.

Tokens are never returned to a browser, logged, placed in generic metadata, or included in connection reads. **Schema prepared, runtime credential storage disabled:** no real Integration Core credential may be written until authenticated envelope encryption backed by a rotated KMS/secret-manager key (or Supabase Vault after operational validation) is implemented and audited. The existing application AES-GCM helper remains legacy and is not reused automatically. Caller-provided ciphertext, Base64, and plaintext disguised as ciphertext are forbidden. Once implemented, refresh tokens will be per-connection, backend-only, replaced on rotation, cleared on disconnect, and invalidated on `invalid_grant`/401.

OAuth client secrets, webhook secrets, encryption keys, and bot tokens live in environment secret stores. Rotation supports overlap where providers allow it, deploys the new version, re-encrypts lazily by key version, then retires the old secret. Dev, Preview, Staging, and Production use distinct OAuth applications/callback allowlists, webhook endpoints, secrets, and databases; production grants/tokens must never enter Preview.
