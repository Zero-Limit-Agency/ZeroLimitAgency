# Workspace Core product definition

Workspace Core is the shared operating layer beneath Personal, Creator, and Team. It includes identity, space selection, access, entitlements, core settings, lifecycle, permissions, membership for Team, audit and module discovery. It does not include professional dashboards or tools.

Personal varies through `spaces.personal_profession`, not separate architectures. Creator remains an owned workspace. Team's organization, canonical owner, members, roles and invitations are foundational collaboration controls. Legacy client/application access remains a separate product history.

The core is complete for this phase when the chain **Space → Core → Registry → compatibility → activation → authorization → route/navigation** works without exposing a real business module. Commercial catalogue, billing, advanced settings, Creator collaboration and final tool selection are deferred product decisions.
